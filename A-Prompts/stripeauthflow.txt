First, once a user makes a payment on the GetKaivo website via Stripe, Stripe will send a webhook event to our backend. Our system will have a webhook endpoint that listens for this event. When the payment is confirmed, our backend will receive the event, and it will check that the payment was successful.

Once the payment is confirmed, we will extract the user’s email or other relevant details from the webhook payload. After that, we will call an internal API that we have on our agency platform. This API will generate a magic link for the user and send it to the email we extracted. In summary, the webhook acts as a trigger: it confirms the payment, and once we get that confirmation, we securely send out the magic link so the user can log in. This ensures that only paying users get access via the magic link, and the process is fully automated.
